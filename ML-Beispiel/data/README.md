# Prepared public data

`model_input.csv` was generated by `../data_pipeline.py` from the public
cBioPortal study `prad_tcga_pan_can_atlas_2018`.

- One row represents one TCGA patient/sample.
- `fusion_status` is 1 only when the structural-variant records contain the
  partner pair TMPRSS2 and ERG.
- `clinical__*` columns contain age and pathological T/N stage.
- `expr__*` columns contain `log2(batch-normalized RSEM + 1)` expression values.
- Direct fusion-marker expression (`ERG`, `TMPRSS2`) is absent.

Exact source profiles, sample counts, missingness and leakage controls are stored
in `data_manifest.json`. Delete both generated files and rerun
`python data_pipeline.py` to reproduce the table from the API.
